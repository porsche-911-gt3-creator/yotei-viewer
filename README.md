# 予定ビューア

田舎館村役場グループウェアの予定を、スマホで見るためのアプリ(ホーム画面に追加して使うWebアプリ)です。

- 役場PCのグループウェアで、カレンダーの「📱 スマホへ送る」を押すと、画面にQRコードが次々に表示されます。
- このアプリの「📷 更新」を押して画面にかざすと、全部のQRを読み取って予定を取り込みます。
- 予定データはスマホの中(ブラウザの保存領域)だけに保存され、どこにも送られません。このリポジトリにも予定データは置きません。
- 一度開けば、電波がなくても見られます。
- 右上で「一覧」と「カレンダー」(月ごと)を切り替えられます。カレンダーは日を押すとその日の予定が下に出て、左右にスワイプすると月が変わります。

## 使い方

1. スマホで https://porsche-911-gt3-creator.github.io/yotei-viewer/ を開く
2. ホーム画面に追加する(iPhone: 共有ボタン →「ホーム画面に追加」/ Android: メニュー →「ホーム画面に追加」)
3. ホーム画面のアイコンから開き、「📷 更新」でPCの画面にかざす

## ファイル

- `index.html` / `app.js` … 画面と読み取り処理
- `jsQR.js` … QR読み取り部品(jsQR 1.4.0, Apache-2.0)
- `sw.js` … オフラインで開くための保存処理
- `manifest.webmanifest`, `icon-*.png` … ホーム画面用の設定とアイコン

PC側の送信処理は、グループウェア本体の `renderer/phone-sync.js` にあります。
